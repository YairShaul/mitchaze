# מתחזה

משחק מסיבה: כולם מקבלים מילה סודית, אחד מקבל רק רמז. מי המתחזה?

לשחק: https://yairshaul.github.io/mitchaze/

- טלפון אחד: מעבירים מיד ליד.
- כל אחד מהטלפון שלו: הטלפון של המנהל מחבר את כולם ישירות (PeerJS), בלי שרת ובלי חשבון.

## עדכון
הקוד נמצא ב-`source/`. אחרי שינוי מריצים:

    powershell -ExecutionPolicy Bypass -File source\build.ps1 -Out .

הסקריפט בונה את `index.html`, הסמלים והקבצים של האפליקציה בתיקייה הראשית. כשמשנים קבצים, מעלים את `VERSION` ב-`source/web/sw.js`.
